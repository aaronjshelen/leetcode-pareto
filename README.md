# LeetCode Pareto

My solutions and notes for the LeetCode Pareto problem set.

## Structure

Each problem has its own folder:

```text
problems/
├── 001-two-sum/
│   ├── solution.py
│   └── notes.md
├── 121-best-time-to-buy-and-sell-stock/
│   ├── solution.py
│   └── notes.md
```

* `solution.py` — My solution to the problem
* `notes.md` — Key ideas, patterns, complexity, and takeaways
